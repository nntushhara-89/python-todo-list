# python-todo-list
A simple command-line to-do list application built with Python.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Validate user input
- Interactive menu

## Requirements

- Python 3

## How to Run

1. Open the repository in GitHub Codespaces.
2. Open the terminal.
3. Run:

   ```bash
   python main.py
   ```

## How to Use

Choose an option from the menu to view, add, complete, or delete tasks.
Choose option 5 to exit the application.

## Concepts Practiced

- Lists and dictionaries
- Functions
- Loops and conditional statements
- Exception handling
- User input
- List indexing and enumerate

## Limitations

Tasks are stored in memory and are not saved after the program exits.
